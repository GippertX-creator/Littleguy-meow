## V0.2 设计资料包

[点击下载 Littleguy-0.2.0-design.zip](https://github.com/GippertX-creator/Littleguy-meow/raw/refs/heads/main/downloads/Littleguy-0.2.0-design.zip)

包含下一版设计稿、照片分析、24 种卧姿和 12 种站立/运动关键姿势的三张概念板，以及行为参数与动画验收要求。解压后先阅读 `下载说明.txt`；姿势图片在 `concepts/` 中。

V0.2 目前处于设计阶段，资料包没有新版可执行程序。需要运行桌宠，请下载下方 V0.1 Windows 试用包。

## V0.1 Windows 试用包

[点击下载 Littleguy-0.1.0-win-x64.zip](https://github.com/GippertX-creator/Littleguy-meow/raw/refs/heads/main/downloads/Littleguy-0.1.0-win-x64.zip)

适用于 Windows 10/11 x64，约 69 MiB。也可以打开本目录的 ZIP 文件，点击 GitHub 页面右上角的 **Download raw file（下载原始文件）**。

下载后右键 ZIP，选择“全部解压缩”，打开解压后的文件夹并双击 `Littleguy.exe`。无需另装 .NET。使用说明和 Windows 验收清单包含在 ZIP 中。

本版支持光标互动、摸头、拖动、揣手、翻肚皮、睡觉、大小调整、安静模式、鼠标穿透和托盘菜单。外观是根据仓库原图制作的二维透明姿势素材。

验证状态：15 项行为与素材检查通过，Windows x64 交叉编译通过；Windows 桌面真机交互尚未验收，试用包附有自动自检入口。程序尚未做代码签名。

SHA-256 校验值见同目录 `Littleguy-0.1.0-win-x64.zip.sha256`。
